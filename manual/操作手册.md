# DanmuQueue 操作手册（Windows）

这个文件夹专门放 Windows 版的使用说明和配置模板。

## 文件说明

- `操作手册.md`：给主播或运营看的快速说明
- `config.local.example.json`：配置模板，复制后改名为 `config.local.json`

## 1. Windows 下配置文件放哪里

### 打包版（Windows `.exe`）

把 `config.local.json` 放到：

```text
%APPDATA%\DanmuQueue\config.local.json
```

也就是类似下面这个路径：

```text
C:\Users\你的用户名\AppData\Roaming\DanmuQueue\config.local.json
```

### 源码运行版

如果你是直接在项目里运行 `app.py`，就把 `config.local.json` 放在项目根目录，和 `app.py` 同级。

## 2. config 每一项是干什么的

`config.local.example.json` 的内容如下：

```json
{
  "room": "11113452",
  "keyword": "排队\n上车",
  "eligibility_mode": "historical",
  "required_guard_level": 3,
  "allow_repeat": false,
  "cookie": ""
}
```

- `room`：直播间号，支持短号，程序会自动解析真实房间号
- `keyword`：入队关键词，建议一行一个，也支持逗号、中文逗号、分号、竖线分隔
- `eligibility_mode`：资格来源
  - `historical`：曾经上过舰才算
  - `current`：当前在舰才算
  - `all`：当前在舰和曾经上过舰都算
- `required_guard_level`：最低舰队等级
  - `3` = 舰长
  - `2` = 提督
  - `1` = 总督
- `allow_repeat`：是否允许同一个人重复排队
- `cookie`：B 站登录 Cookie，可先留空，之后再补

## 3. 软件怎么用

1. 先把 `config.local.json` 放到上面的正确位置
2. 启动软件
3. 在界面里确认房间号、关键词、资格规则和 Cookie
4. 点击“连接”
5. 进来的弹幕只要命中关键词并满足资格，就会进入队列

## 4. 导出

- 点击“舰长 CSV”，可以随时导出舰长名单
- 点击“排队 TXT”，可以随时导出当前排队结果
- 导出不会清空队列，可以反复执行

## 5. 关键词填写建议

推荐一行一个关键词，例如：

```text
排队
上车
报名
```

如果你更习惯，也可以写成：

```text
排队,上车,报名
```

## 6. Cookie 的作用

Cookie 主要用于：

- 获取更完整的登录态信息
- 提高房间信息和弹幕接口的成功率
- 辅助判断舰长 / 提督 / 总督资格

如果连接时提示 `-352`、获取弹幕服务器失败，或者资格判断不准，优先把 Cookie 填上再试。
